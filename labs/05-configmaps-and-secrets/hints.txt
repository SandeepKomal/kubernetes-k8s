`kubectl describe pod -l app=checkout` names exactly what is missing. Then
compare the keys in `kubectl get configmap checkout-config -o yaml` with the
keys the Deployment asks for.
---
Keys are case sensitive: `payment_mode` is not `PAYMENT_MODE`. The Secret
does not exist yet: `kubectl create secret generic --help`.
---
kubectl create configmap checkout-config --from-literal=PAYMENT_MODE=sandbox --dry-run=client -o yaml | kubectl apply -f -
kubectl create secret generic checkout-secrets --from-literal=API_TOKEN=sandbox-123
kubectl rollout restart deployment/checkout
