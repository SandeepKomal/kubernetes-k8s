# Contributing

Contributions that improve the accuracy, clarity, and practical value of this Kubernetes repository are welcome.

## Good contributions

- Correcting inaccurate Kubernetes examples
- Adding practical manifests
- Adding troubleshooting guides
- Improving documentation
- Adding CKA/CKAD-oriented examples
- Updating examples for current Kubernetes APIs
- Adding AWS EKS examples with clear prerequisites

## Before opening a pull request

1. Explain what the change solves.
2. Keep examples focused and easy to reproduce.
3. Avoid committing credentials, tokens, private keys, kubeconfigs, or other secrets.
4. Validate YAML syntax and Kubernetes API versions where practical.
5. Update the README or relevant documentation when adding a new learning topic.

## Pull requests

Please include:

- What changed
- Why it changed
- How it was tested
- Any cluster/version prerequisites

Small, focused pull requests are easier to review and maintain.
