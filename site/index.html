    Start in two minutes

    On your machine

    Needs Docker, kind and kubectl. Free.

    # 1. Get the course
git clone https://github.com/SandeepKomal/kubernetes-k8s.git
cd kubernetes-k8s

# 2. Check Docker, kind and kubectl
./nimbus doctor

# 3. Create the cluster (1-2 minutes)
./nimbus up

# 4. Open the practice dashboard
./nimbus ui

# 5. Done? Delete the cluster to free
#    memory. Your progress is kept.
./nimbus down

    In your browser

    Nothing to install. Uses your own free GitHub Codespaces hours.

    Open in Codespaces

    When you finish, stop the codespace (Codespaces menu, Stop current codespace) so it stops using your free hours. Delete it at github.com/codespaces when you no longer need it, to free its storage.

    Your path

    Progress is saved in this browser only. Tick a level when ./nimbus check passes.

    Quiz

    Scenario-based questions for every level, from first Pod to production. You see right or wrong as soon as you answer, with the reasoning, which is where the learning is.
