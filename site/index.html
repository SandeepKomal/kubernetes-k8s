Learn Kubernetes by fixing it.

Fifteen levels, each a ticket from the on-call queue of Kubelet Kitchen, a made-up startup. Every level starts with something broken in your own practice cluster. You fix it, and ./quest check tells you when you are right.

git clone https://github.com/SandeepKomal/kubernetes-k8s.git
cd kubernetes-k8s
./quest up        # local kind cluster
./quest start 0

Progress is saved in this browser only. Tick a level when ./quest check passes.
